Midterm

This program utilizes a BankAccount class that has a variable for balance and functions that deal with handling transactions and deposits. These are all recorded into a text file.
First, you can enter in a value to deposit into your balance. Then, you can enter in an item name and its price, and the price will be deduced from your balance.
Lastly, everything is printed at the end.
This program can also get the balance from the file so it can be used in the program.
